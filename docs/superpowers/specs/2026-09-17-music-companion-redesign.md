# 音乐 AI 伴侣精简重设计

## 目标

把现有粗糙、入口混乱的双前端收敛为一个可直接运行的音乐伴侣页面。用户打开 Flask 首页即可聊天和播放音乐，不再看到失效的角色、天气或调试功能。

## 视觉方向

采用“唱片桌面”风格：浅色纸张背景、墨黑文字、唱片红作为唯一强调色。首屏以正在播放的唱片卡和对话为核心，不复制 QQ 音乐或网易云音乐的品牌外观，只借鉴其清晰层级和播放器优先原则。

## 页面结构

1. 顶部：产品名、简短在线状态。
2. 播放区：唱片视觉、歌曲名、歌手、浏览器原生音频控件；未播放时展示安静的空状态。
3. 对话区：欢迎语、用户与伴侣消息、精简的三个快捷提问。
4. 底部：固定输入框和发送按钮，明确显示等待、错误和重试状态。

## 删除与保留

删除前端中的工具目录、调用轨迹、会话 ID、角色切换、新建角色、天气、早安消息和今日歌单独立入口。保留后端 Agent、长期记忆、SSE 流式回复、搜索与播放工具；调试与追踪接口保留在后端但不暴露在主界面。

## 入口与错误处理

- Flask `/` 直接提供 React 构建产物，消除旧模板和 `file://` 错误入口。
- 开发环境继续由 Vite 代理 `/api` 到 Flask。
- SSE 请求增加超时、响应类型检查和未完成流保护。
- 聊天失败时展示可理解的错误消息，并允许用户重新发送。
- 搜索接口限制 `limit` 的范围并处理非法参数，避免 500。

## 验收标准

- `http://127.0.0.1:5050/` 可直接打开新版页面。
- 页面不再出现永久“加载中”、失效角色按钮或多余工具信息。
- Demo 模式下发送消息能得到回复；播放工具事件能驱动原生音频播放器。
- 桌面和手机宽度均无横向溢出，输入区可用。
- 前后端测试、生产构建和关键安全检查通过。
